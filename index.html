MLBB Video Generator

MLBB Video Generator is a desktop tool for creating and publishing short-form Mobile Legends: Bang Bang videos. It helps creators generate scripts, voiceovers, and vertical videos, then publish content to TikTok using the TikTok Content Posting API with user-approved settings such as caption, hashtags, and privacy.

Features

  • Create short-form vertical videos for Mobile Legends: Bang Bang.
  • Generate captions and publishing metadata.
  • Publish to TikTok through TikTok Content Posting API (Direct Post) after user authorization.
